The sample database

students (student_id, first_name, last_name, form, parish, age) and results (result_id, student_id, subject, score, term). Run SELECT * FROM students; to look around. You can also try INSERT, UPDATE and DELETE: use Reset database to start again.

Common SQL for the exam

SELECT, WHERE and ORDER BY

SELECT first_name FROM students WHERE form = 5 ORDER BY last_name; picks columns, filters rows, then sorts them.

Aggregates and GROUP BY

SELECT subject, AVG(score) FROM results GROUP BY subject; gives one row per subject. Use HAVING to filter groups.

JOIN

SELECT first_name, score FROM students JOIN results ON students.student_id = results.student_id; matches rows through the key they share.
